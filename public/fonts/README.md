# Smiley Sans

`SmileySans-Oblique.ttf.woff2` 来自 [atelier-anchor/smiley-sans](https://github.com/atelier-anchor/smiley-sans) v2.0.1，是页面标题字体的来源文件。页面实际加载的是 `src/app/fonts/flacier-display.woff2`：`scripts/subset-display-font.py` 按 `src/app` 与 `src/config` 中出现的字符裁出的子集，由 Vite 加内容哈希并长期缓存。改动标题或分组名后重新运行该脚本。

字体按 SIL Open Font License 1.1 发布，许可文本见 `OFL-SMILEY-SANS.txt`。

站点标志和 favicon 中的「の」取自该字体的字形轮廓。
